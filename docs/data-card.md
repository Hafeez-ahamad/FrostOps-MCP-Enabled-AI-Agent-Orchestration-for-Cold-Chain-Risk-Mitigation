# Data card

## Summary

| | |
|---|---|
| Primary data | **Synthetic.** Generated by the seeded simulator in `sim/` (a fictional Southern California refrigerated fleet). |
| Real data | None. No real vehicles, carriers, shipments, customers or people. |
| Personal data | None. Vehicle and shipment ids are generated (`VEH-001`, `S0001-00001`). The demo API users are role placeholders. |
| Optional stress set | Kaggle "Logistics and Supply Chain Dataset" (<https://www.kaggle.com/datasets/datasetengineer/logistics-and-supply-chain-dataset>). Not committed; loaded only by `python -m engine.data.kaggle`, into its own table. |
| SOP | `data/policy/cold_chain_sop.md`, written for this project. A short illustrative procedure, not a real company document. |

## Synthetic fleet (headline data)

- **Fleet:** 50–200 vehicles across five invented depots.
  - Coordinates are approximate Southern California city locations, used only for distances.
  - Facility and destination names are invented.
- **Cargo bands:**
  - FRESH 0–4 °C comes from the SOP.
  - FROZEN −25 to −15 °C and PHARMA 2–8 °C are configuration assumptions (`policy/cargo_types.yaml`).
- **Physics, delays and congestion:** simple documented models (`docs/simulator.md`). They are illustrative, not calibrated to any real trailer, route or port.
- **Ground truth:**
  - Every seeded incident has its true start, true breach time and an oracle-best action.
  - Every glitch has its type and affected readings.
- **Clean data is kept below every SOP threshold by construction.** Every rule hit therefore maps to a labelled incident. This makes detection precision a test of the pipeline's logic, not of real-world sensor behaviour.
- **Reproducible:** the same scenario and seed give byte-identical output.

### Known biases and limits

- **Seeded noise:**
  - Noise comes in eight specific forms (spike, flatline, dropout, duplicate, out-of-order, °F/°C mix-up, GPS jump, clock skew).
  - Glitches never overlap a real incident on the same truck.
  - Real sensor faults are messier and can coincide with real breaches.
- **Seeded incidents:** incidents are seeded at chosen hours. Real incident rates, durations and seasonality are unknown here.
- **Oracle:** the "oracle" action is a fixed mapping from the true incident type (`sim/oracle.py`), not an optimiser.
- **Outcomes:** they are counterfactual degree-minutes from the same simple physics, with assumed effect delays (`eval/EVAL.md`). They are simulated and must be labelled as such.

## Kaggle stress set

- **Shape:** 32,065 hourly rows, 2021–2024.
  - Coordinates span the continental US, not Southern California.
  - 27% of rows are above 4.0 °C, with no shipment or vehicle ids.
- **Use:** only to stress the ingestion and data-quality code. It never appears in any reported result.
- **Licence:** **check the dataset's licence on Kaggle before redistributing it or any derivative.** The file stays out of git (`.gitignore`: `data/raw/`).
